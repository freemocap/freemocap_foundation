# Minsky (1974) — A Framework for Representing Knowledge
**Citation:** Minsky, M. (1974). *A Framework for Representing Knowledge*. MIT-AI Lab Memo 306. `@minsky1974`

**What it is:** Proposes **frames** — structured bundles of expected properties ("slots") with **default values that can be overridden** by specifics (a "bird" frame defaults `can-fly: yes`; a penguin overrides it). Credited with posing the challenge formal logic couldn't yet meet: real reasoning retracts conclusions when new facts arrive.

**Why we cite it:** The **deepest root** of the entity-trait-**override** idea in [[composition-over-inheritance]]. Names the exact "defaults with exceptions" mechanism the sensor-grounded ontology needs (and that biology is full of — [[shared-vs-unshared-traits|cavefish, ferret-vs-mouse]]). Ancestor of [[reiter1980]] and [[touretzky1986]].
