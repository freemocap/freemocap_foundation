# Reiter (1980) — A Logic for Default Reasoning
**Citation:** Reiter, R. (1980). A Logic for Default Reasoning. *Artificial Intelligence* 13(1–2), 81–132. `@reiter1980` · doi:10.1016/0004-3702(80)90014-4

**What it is:** One of the 1980 formalisms for **non-monotonic reasoning** (alongside McCarthy's circumscription): rules of the form "birds fly, *unless* known otherwise." The canonical Tweety/penguin example lives here.

**Why we cite it:** The **formal ancestor** of the override layer — the rigorous version of "specific cases defeat general defaults." Supports the argument that overriding is not a nice-to-have but the technically hardest, most load-bearing part of a real-world data model ([[composition-over-inheritance]]), and that monotonic OWL famously *can't* express it (motivating the pragmatic choice, [[the-ontology-question-in-science]]).
