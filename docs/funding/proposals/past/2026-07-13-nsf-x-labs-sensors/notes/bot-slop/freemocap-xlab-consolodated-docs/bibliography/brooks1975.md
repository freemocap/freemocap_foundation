# Brooks (1975) — The Mythical Man-Month
**Citation:** Brooks, F. P. (1975). *The Mythical Man-Month: Essays on Software Engineering.* Addison-Wesley. `@brooks1975`

**What it is:** The field's foundational essays; here for **"Plan to throw one away; you will, anyhow"** — the first system is a pilot whose real value is teaching you the requirements you couldn't know at the start. (Frederick Brooks — not Rodney, [[brooks1991]].)

**Why we cite it:** The engineering legitimacy of the **blank-page refactor** ([[path-dependence]] C5). FreeMoCap's 3–4 refactors are Brooks's pilot-system discipline; each escaped a path-dependent complexity ceiling. Sets up the Spolsky counterpoint ([[spolsky2000]]) — whose danger (a *market* clock) doesn't apply to precompetitive science.
