# The Bermuda Principles (1996)
**Citation:** Human Genome Project / Wellcome Trust (1996). *Summary of Principles Agreed at the International Strategy Meeting on Human Genome Sequencing (Bermuda Principles).* `@bermuda1996` · genome.gov

**What it is:** The HGP norm mandating **release of DNA sequence within 24 hours** of generation into the public domain — a data-sharing culture imposed early by community + funders, which became the archetype for rapid release.

**Why we cite it:** The precedent for **setting the sharing culture at the very start** ([[tiered-dissemination-and-communal-science]]): a funder/consortium can simply mandate a release norm, and the downstream value is enormous. Supports the "uncertainty-tagged data + release norm from Phase 0" recommendation.
