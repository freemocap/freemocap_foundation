# FreeMoCap (the anchor and proof-of-concept)

The open-source, markerless motion-capture platform that is the **named starting point** — the seed from which the broader instrument is built. Its lineage is strategically right: **open, markerless, commodity-hardware, community-driven** — the correct cultural/technical starting point for the one piece of the landscape nobody else is structurally incentivized to build (see [[competitive-terrain]]).

FreeMoCap is the **anchor for the capture layer, not the whole vision.** The vision is the integrated, calibrated, multimodal, semantic instrument that capture feeds ([[complete-empirical-capture]]). Its very existence is **proof-of-concept** that the open, community-tool approach works; X-Labs-scale support accelerates the model to global scale.

## Community & structure (confirm figures `#verify`)
- Outline cites ~**15k users across 150+ countries**, ~**10k GitHub stars**, ~**3.5k Discord members**. `#verify`
- Poly-repo: `core`, `skellycam`, `skellytracker`, `skellyforge`, `skellyblender`.
- Governed by the **FreeMoCap Foundation, Inc.** (501c3), founded by [[personnel|JSM]] in 2021.
- Its **3–4 blank-page refactors** are the [[path-dependence|Brooks pilot-system discipline]] in action — the tool "does the same thing" but occupies a wildly larger capability envelope each time.
