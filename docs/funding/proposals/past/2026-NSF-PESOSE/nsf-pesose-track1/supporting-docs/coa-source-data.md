# COA source data — paste into NSF's template

Working notes. Not uploaded. The thing you upload is NSF's `.xlsx`.

## The process, in full

1. Download the template: **https://www.nsf.gov/funding/senior-personnel-documents**
   (Collaborators and Other Affiliations template, ~26 KB `.xlsx`)
2. Fill the five tables. One file per person, so two files.
3. Save as `.xlsx` — not `.xls`, not PDF, not Google Sheets.
4. Upload each in Research.gov under Senior/Key Personnel Documents →
   Collaborators and Other Affiliations.

Download a fresh copy rather than reusing an old one; the table structure has
changed between versions and an outdated structure gets rejected.

**Nobody reviews this for prose quality.** It is a Single Copy Document — NSF
staff only, never shown to reviewers. Its one job is to stop your collaborators
from being assigned as your reviewers. Names and organizations in cells. That's
it. Over-inclusion is harmless; omission is the only real failure mode.
