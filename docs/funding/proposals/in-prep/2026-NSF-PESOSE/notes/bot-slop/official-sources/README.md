## The trap in this solicitation

> "**Proposers must review the PESOSE website for critical information on proposal and budget preparation.**"
> — NSF 26-506, Important Information and Revision Notes

That is not boilerplate. The bot confirmed by string search that **`173.33`, `de minimis`, the 75th-percentile BLS salary rule, the $30,000 I-Corps cap, and the 3–5 person team requirement appear nowhere in the solicitation PDF.** They exist only on the 2026-03-09 update page. Anyone working from the PDF alone will build a non-compliant budget.
