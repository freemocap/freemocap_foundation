## Project Overview:
_500 words_
Quantitative movement data are widely used in rehabilitation research to characterize gait, balance, motor performance, and changes in function over time. However, biomechanical datasets are often difficult to combine or reuse because motion-capture systems and analysis pipelines differ in how they represent time-series measurements, metadata, coordinate systems, anatomical landmarks, derived measures, and processing history. These differences limit the ability to aggregate movement datasets across studies and technologies.

The objective of this project is to harmonize existing gait and balance datasets containing markerless and reference motion-capture measurements within the evolving DAPR data framework. The datasets include synchronized biomechanical time-series data such as three-dimensional body trajectories, joint angles, center-of-mass measures, gait events, task conditions, and associated acquisition and processing metadata. The data include outputs generated using multiple pose-estimation approaches as well as measurements from a laboratory marker-based motion-capture system, providing an opportunity to distinguish information that is specific to an acquisition or processing method from information that describes the underlying biomechanical measurement.

We will work with the DAPR Resource Core to map participant, trial, task, and biomechanical variables to existing rehabilitation data standards and DAPR terminology where appropriate. Particular attention will be given to elements required to interpret biomechanical time-series data, including anatomical definitions, measurement units, sampling characteristics, coordinate systems, task conditions, and processing provenance. Where existing terminology is insufficient, we will identify gaps and collaborate with DAPR to develop or refine terms and metadata conventions needed to represent gait and related movement data.

The project will produce a harmonized, documented representation of the existing gait and balance datasets together with reusable mappings and guidance for representing similar biomechanical datasets. The resulting resource will provide a practical test case for incorporating movement time-series data into the DAPR ecosystem and support future aggregation of rehabilitation datasets collected using different motion-capture and movement-analysis technologies.

## DAPR Resources and Relevance
_200 words_
This project would use consultation and harmonization support from the DAPR Resource Core to identify appropriate existing data standards, map study variables into the evolving DAPR framework, and develop new DAPR data terms where biomechanical time-series concepts are not yet adequately represented. Guidance would also be valuable for determining how complex longitudinal signals and their associated metadata should be structured for future integration with DAPR infrastructure.

The proposed work directly supports DAPR's goal of expanding the range of rehabilitation data that can be aggregated and reused. Biomechanical time-series data are common in gait, balance, and movement research but present harmonization challenges that differ from conventional tabular clinical datasets. By using existing datasets to work through these challenges, this project will provide a reusable example for integrating gait and movement data collected with different technologies. The resulting harmonized datasets and documentation will support future data sharing, cross-study analyses, and larger-scale rehabilitation data science projects.
