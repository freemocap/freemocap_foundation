# Palantir — Ontology Documentation
**Citation:** Palantir Technologies (2024). *Ontology: Overview, Core Concepts, and the Ontology System.* `@palantir_docs` · palantir.com/docs

**What it is:** Primary-source docs for Palantir's **executable ontology** — object/property/link (semantic) + action/function (kinetic), framed as "Language, Engine, Toolchain." Explicitly built *beyond* the RDF/OWL Semantic Web stack for governed operational decisions.

**Why we cite it:** The headline precedent that a serious operational system **deliberately eschewed OWL/RDF** and built to spec — direct support for [[build-to-spec-vs-shared-protocols]] and the [[the-ontology-question-in-science|pragmatic-over-formal]] choice. Also the source for the [[palantir-ontology|typed-primitive vocabulary]] the scientific analog reinvents. (Web-source; cite carefully.)
