# Robbins et al. (2021) — Hierarchical Event Descriptors (HED)
**Citation:** Robbins, K., Truong, D., Appelhoff, S., Delorme, A., & Makeig, S. (2021). Capturing the Nature of Events... using Hierarchical Event Descriptors. *NeuroImage* 245, 118766. `@robbins2021` · doi:10.1016/j.neuroimage.2021.118766

**What it is:** **HED** — the event-annotation standard for [[bids-and-nwb|BIDS]], with implicit ontological representations but a deliberately intuitive interface plus extensible library schemas. The **pragmatic-over-formal** winner.

**Why we cite it:** The closest thing the field has to an event ontology — and the key evidence that formal ontologies lost to pragmatic annotation ([[the-ontology-question-in-science]]). Cite HED's own admission that current frameworks can't handle real-world complexity for the novelty argument. But HED tags *events*; it is not the operational model of the continuous interaction stream — that's [[the-missing-middle]].
