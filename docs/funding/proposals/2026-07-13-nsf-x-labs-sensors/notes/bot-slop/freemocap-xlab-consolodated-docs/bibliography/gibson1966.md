# Gibson (1966) — The Senses Considered as Perceptual Systems
**Citation:** Gibson, J. J. (1966). *The Senses Considered as Perceptual Systems*. Houghton Mifflin. `@gibson1966`

**What it is:** Gibson's earlier work reframing the senses not as passive channels but as **active perceptual systems** that seek out information in ambient energy — the precursor to the 1979 ecological synthesis.

**Why we cite it:** Supports the framing that perception is an active sampling of [[eaee|environmental energy]] — the same category of act the instrument performs. A secondary anchor to [[gibson1979]] for the ecological-optics spine; useful if the argument needs the "perceptual systems as active samplers" emphasis.
