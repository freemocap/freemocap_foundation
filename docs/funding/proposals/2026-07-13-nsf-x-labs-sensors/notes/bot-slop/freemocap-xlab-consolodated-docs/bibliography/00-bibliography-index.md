# 📚 Bibliography Index

The reference layer of the vault. Each note here describes **one cited source** — its contents, main ideas, and *why we cite it here* (a short relevance analysis) — and maps to a `@citekey` in the canonical bibliography **`proposal/FMCF-NSF-XLABS.bib`**.

> [!note] Separation of concerns
> These `#citation` notes are **kept separate from the citing instances** in the core [[00-MOC|concept/thread/integrative]] notes. The core notes *use* the ideas and link to the concept; these notes *analyze the source* and link back to where it's used. To actually cite in the Typst proposal, use `@citekey` (e.g. `@harnad1990`).

## How to use
- Adding a citation to the proposal? Find the source here → grab its `@citekey` → cite in the `.typ` file → the entry is already in `FMCF-NSF-XLABS.bib`.
- `verification:` frontmatter on each note: **verified** (web-checked this session), **carried** (DOI carried from the advisory series; standard for a canonical work but not re-checked), **needs-check** (flagged; see [[_verification-punchlist]]).
