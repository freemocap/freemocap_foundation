# Bilas (2002) — A Data-Driven Game Object System
**Citation:** Bilas, S. (2002). *A Data-Driven Game Object System*. GDC, San Jose. `@bilas2002`

**What it is:** The founding public description of an **entity-component system** (Dungeon Siege): game objects assembled from self-contained components configured in data, with instancing and override support — ~7,300 object types and 100k+ placed objects that would be unmaintainable as an inheritance tree.

**Why we cite it:** Historical origin of [[entity-component-system|ECS]] — the "composition at massive combinatorial scale" precedent that directly informs the multimodal-data model. Pair with [[ford2017]] (Overwatch) for the "composition wins on maintainability *and* performance" argument.
