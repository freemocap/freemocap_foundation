# Sweller (1988) — Cognitive Load During Problem Solving
**Citation:** Sweller, J. (1988). Cognitive Load During Problem Solving: Effects on Learning. *Cognitive Science* 12(2), 257–285. `@sweller1988` · doi:10.1207/s15516709cog1202_4

**What it is:** Founding statement of **Cognitive Load Theory**: working memory has strictly limited capacity, and **extraneous load** (imposed by poor presentation rather than intrinsic difficulty) directly degrades learning/performance.

**Why we cite it:** Grounds the claim that the **scientist-facing interface is part of the measurement chain**. The system under study is effectively infinite-dimensional, so intrinsic load is irreducibly high — minimizing *extraneous* load is the only lever, and it's decisive for whether the instrument is usable at all. Ties complexity-management and cognitive-load-management as two ends of one chain ([[sensor-grounded-ontology]]) and underwrites usability-as-adoption ([[opensim]] as the anti-example, [[conceptual-cleanliness-four-audiences]]).
