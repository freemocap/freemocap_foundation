# Eghbal (2020) — Working in Public
**Citation:** Eghbal, N. (2020). *Working in Public: The Making and Maintenance of Open Source Software.* Stripe Press. `@eghbal2020`

**What it is:** Classifies open projects by user-growth × contributor-growth into **federations** (Linux/Wikipedia), **clubs** (Astropy — users are developers, self-maintaining), **stadiums** (huge passive audience, tiny maintainer core — the burnout trap), and **toys**.

**Why we cite it:** The organizing lens for the [[tiered-dissemination-and-communal-science|dissemination/governance]] target: a **club-like core** (antidote to abandonware) engineered toward a **federation**, designed *against* the **stadium**. Naming this quadrant target is a governance-structure argument the X-Labs org criterion wants ([[bdfl-governance]]).
