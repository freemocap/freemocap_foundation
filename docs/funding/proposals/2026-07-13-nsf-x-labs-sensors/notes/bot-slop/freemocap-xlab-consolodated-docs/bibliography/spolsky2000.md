# Spolsky (2000) — Things You Should Never Do, Part I
**Citation:** Spolsky, J. (2000). *Things You Should Never Do, Part I.* `@spolsky2000` · joelonsoftware.com

**What it is:** Calls rewrite-from-scratch "the single worst strategic mistake" a software company can make (Netscape's 3-year rewrite gap as the cautionary tale).

**Why we cite it:** The **honest counterpoint** that *strengthens* the case when addressed head-on ([[path-dependence]] C5): Spolsky's danger is a **market penalty** — "a 2–3 year gift to competitors." **Precompetitive scientific infrastructure has no market clock**, so the strongest objection to periodic refactors doesn't apply. Removing the clock (what an autonomous X-Lab does) makes the healthy refactor possible — *the objection becomes the justification.*
