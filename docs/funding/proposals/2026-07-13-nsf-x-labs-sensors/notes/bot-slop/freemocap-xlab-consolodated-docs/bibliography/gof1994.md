# Gamma, Helm, Johnson & Vlissides (1994) — Design Patterns
**Citation:** Gamma, E., Helm, R., Johnson, R., & Vlissides, J. (1994). *Design Patterns: Elements of Reusable Object-Oriented Software*. Addison-Wesley. `@gof1994`

**What it is:** The canonical patterns book. Two things we use: the maxim **"favor object composition over class inheritance"** (printed as a first-principles rule), and the **Adapter pattern** (a boundary object converting your internal interface to a foreign one).

**Why we cite it:** The software-doctrine anchor for [[composition-over-inheritance]] (the "favor composition" proverb) *and* for [[build-to-spec-vs-shared-protocols]] (the Adapter pattern = "build the core to spec, add [[lab-streaming-layer|LSL]] compatibility as a boundary adapter"). Both traps in [[the-two-traps]] cite this.
