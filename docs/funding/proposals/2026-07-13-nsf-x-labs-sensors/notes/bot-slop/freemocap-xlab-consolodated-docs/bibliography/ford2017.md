# Ford (2017) — Overwatch Gameplay Architecture and Netcode
**Citation:** Ford, T. (2017). *Overwatch Gameplay Architecture and Netcode*. GDC. `@ford2017`

**What it is:** Blizzard's account of an OOP→**ECS** refactor: entities are bags of components; Systems operate on all entities with a given component set. The original OOP architecture "struggled to maintain tick budgets as hero complexity increased," driving the multi-year ECS rewrite to hold a deterministic 60+ Hz sim.

**Why we cite it:** A modern, production-scale ECS case showing composition managing runaway combinatorial complexity — the same pressure heterogeneous multimodal capture faces. Supports [[entity-component-system]] and the [[composition-over-inheritance]] doctrine.
