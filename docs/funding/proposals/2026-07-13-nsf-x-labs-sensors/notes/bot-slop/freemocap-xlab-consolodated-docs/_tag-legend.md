# 🏷️ Tag Legend

The vault uses a small, deliberately flat tag vocabulary so the Obsidian graph and tag-pane stay legible. Every note carries **one note-type tag** and **one or more topic tags**.

## Note-type tags
- `#moc` — map-of-content / navigation hub ([[00-MOC]]).
- `#integrative` — a large document that weaves many threads into one argument (the seven backbone docs).
- `#thread` — a medium note developing one recurring thread.
- `#concept` — an atomic note defining one grounded term or idea.
- `#citation` — a per-reference note in `references/`: what a cited source *is* and *why we cite it*, kept separate from the citing instances in the core notes. Each maps to a `@citekey` in `proposal/FMCF-NSF-XLABS.bib`.
- `#reference` — glossary / personnel / crosswalk / admin.

## Topic tags
- `#thesis` — the core instrument-not-software spine.
- `#architecture` — operational semantic layer, ontology engineering, composition.
- `#ontology` — the sensor-grounded ontology and its concepts.
- `#instrument` — the physical capture apparatus, sensors, the flagship.
- `#metrology` — measurement science, calibration, traceability, uncertainty.
- `#landscape` — the scientific/technology landscape and competitors.
- `#competition` — specific competing efforts and the betweenness argument.
- `#funding-structure` — why normal mechanisms can't build this; org design.
- `#dissemination` — data commons, tiers, publisher/subscriber, communal science.
- `#education` — teaching, boundary objects, field-remaking.
- `#philosophy` — grounding, epistemic gap, Gibson, Kuhn, Quine.
- `#biology` — phylogeny, comparative design, neural substrates.
- `#team` — personnel, collaborators, governance.
- `#x-labs` — the solicitation, criteria, exclusions, proposal mechanics.
