# OBO Foundry (the 25-year org precedent)

**OBO = Open Biological and Biomedical Ontologies** — the **Gene Ontology** and siblings (controlled vocabularies of `is_a`/`part_of`-linked terms) plus a **governance layer** of shared design principles (openness, orthogonality, a common relation set, the **Basic Formal Ontology** upper ontology). Founded from the model-organism communities (1998–2000); the Foundry paper is Smith et al. 2007. Arguably the most successful scientific-ontology effort in existence; BFO is an ISO standard used in 350+ projects.

## Two ways it is a precedent

**As an organizational template `#precedent`** — a *sustained, federated, governed consortium* stewarding durable precompetitive infrastructure that no single lab's grant cycle or company's quarterly clock would produce. A FreeMoCap-stewarded open capture standard is "**OBO but pointed at behavior/neuroscience instrumentation.**" And its **~25-year maturation is the argument, not an embarrassment**: durable shared infrastructure has a decades-long horizon and survives only on sustained, non-market stewardship — exactly the X-Labs funding shape (Phase 0 → Phase 1 ≤$50M/yr → Phase 2 → possible Phase 3).

**As a design cautionary note `#trap`** — OBO is also "clunky under the hood": mandatory **BFO realism** imposes a metaphysics tax; an **OBO-flat-file vs. OWL** format schism must be kept in sync; curation overhead is heavy. So OBO is the model for the *eventual shared layer*, **not** for the [[build-to-spec-vs-shared-protocols|measurement core]] — don't inherit BFO-realism overhead into the instrument. (It also, tellingly, models biology by **composition** of orthogonal terms, not one inheritance tree — [[composition-over-inheritance]] applied to biology by biologists.)
