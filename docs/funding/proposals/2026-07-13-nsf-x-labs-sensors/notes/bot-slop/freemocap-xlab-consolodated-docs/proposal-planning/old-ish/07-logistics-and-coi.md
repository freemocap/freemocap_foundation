# Logistics, COI & Submission — planning

The non-scored-but-required components and the mechanics. Verify **all** format/deadline facts against the official PDFs, not memory.

## Format compliance (proposals that miss this "may be removed from consideration")
- **8 single-sided pages max**, exclusive of COI; single-spaced; **12-pt font**; **1" margins** all sides; 8.5×11; **PDF, no cover letter**. Tables/graphs may use smaller font. `#verify`
- Confirm current DRAFT_MODE toggle is off for the submission build (`proposal/main.typ`).

## Conflicts of Interest (COI) — separate PDF, no page limit
- Describe any potential financial interests of the lead org and Senior/Key Personnel that could conflict; describe how they'll be avoided/neutralized/mitigated. Applies to lead org, employees, subcontractors/consultants.
- Uses FAR Subpart 9.5 as a framework for organizational COI; ongoing disclosure obligation post-award.
- **Action:** enumerate JSM/FreeMoCap Foundation interests + any collaborator/subcontractor interests. `#verify`

## Key dates
- Written proposal due **2026-07-13, 5pm ET**; questions to XLabs@nsf.gov by 2026-07-06.
- Orals (invitation only) **Aug 17–21, 2026**; Oral Package due ~5 business days prior.
- Phase 0 begins **Nov 2026**.

## What carries forward to the oral round (plan now, deliver later)
The oral stage does **not** consider the written proposal — everything must be re-presented. Oral Package = slides (Mission/outcomes, Phase 0 & 1 activities, team, budget summary) + **Phase 0 Milestone Plan** + Senior/Key Personnel disclosures (SciENcv biosketch + current/pending, due ~48h after invite) + **Phase 0 Budget** + signed one-page **Letters of Collaboration**.
- **Action:** line up SciENcv biosketches and Letters of Collaboration early (48h turnaround is tight). `#verify`

## Phase-1 budget note (for Outcomes/Team framing)
Phase 1 requires **three tiered budgets** (essential / mid / comprehensive) to illuminate trade-offs. Keep this in mind when scoping [[03-outcomes|Outcomes]] and facility scale.
