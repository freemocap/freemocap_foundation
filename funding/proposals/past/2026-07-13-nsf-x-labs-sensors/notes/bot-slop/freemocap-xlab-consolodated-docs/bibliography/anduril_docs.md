# Anduril — Lattice SDK Entities Documentation
**Citation:** Anduril Industries (2024). *Lattice SDK: Entities Overview and Entity Manager.* `@anduril_docs` · developer.anduril.com

**What it is:** Primary-source docs for Lattice's **entity-component** model — an entity is a "bag of components" (Asset/Track/Geo-entity), no inheritance hierarchy, published as protobuf schemas. Notably concedes **"ontology alignment remains a work in progress."**

**Why we cite it:** The clearest external instance of [[entity-component-system|ECS]] applied to heterogeneous real-world sensor fusion — the pattern most directly transferable to multimodal scientific data ([[anduril-lattice]]). Its candid "alignment is the hard part" admission is a useful, honest note for our own [[the-ontology-question-in-science|ontology question]]. (Web-source; cite carefully.)
